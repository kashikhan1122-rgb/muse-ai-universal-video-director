# Example: Documentary (10 min, 16:9)

## Prompt (as received)

"A 10-minute documentary about how bees build a hive. Calm narration, macro
footage feel, no staged drama, real behaviour only."

## Production brief (extracted)

- Niche: nature documentary. Style: observational, macro feel, natural light.
- Duration: 10 min → 60 clips, 10 batches. Ratio: 16:9.
- Rules from prompt: no staged drama, real behaviour only — so no invented
  "bee hero" storyline, no anthropomorphic dialogue.
- Narration: calm, factual, paced to the visuals; script written from the
  prompt's facts only, no invented statistics.

## Scene plan (abridged)

| Chapter | Content |
|---|---|
| Arrival | Scout bees find a hollow tree; first comb measurements |
| Building | Wax secretion, comb construction, cell geometry |
| Roles | Queen, workers, drones — behaviour, not characters |
| Defence | Guard bees at the entrance; a real intruder response |
| Seasons | Hive through summer into winter preparation |

## Special rules applied

- No character identity blocks for individual bees (they are not characters);
  instead, a species/appearance block (honeybee, amber-brown, fuzzy thorax)
  repeats verbatim.
- No dialogue. Narration script is a package item; every narration line is
  timed to its chapter, never clipped mid-sentence at a join.
- Any behaviour the generator stages unnaturally (bees "posing", impossible
  flight paths) is a QC failure, retried or reported — documentary honesty
  outranks visual polish.
