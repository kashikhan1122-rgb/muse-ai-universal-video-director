# Environment and Prop Consistency

## Principle

Places and objects are characters too. If a kitchen, a street, a workshop, or a
red bicycle matters to the story, it must look the same in clip 1 and clip 20.

## The environment block

For every location, write one block and reuse it verbatim in every clip prompt
set there:

- Location name and type (room, street, forest, workshop, studio)
- Layout (walls, doors, windows, paths, landmarks — where things are relative
  to each other)
- Architecture and materials
- Landscape and vegetation (if outdoors)
- Weather, time of day, and lighting direction
- Background objects that must stay (furniture, signs, vehicles, trees)
- Colour palette and visual texture
- Signature details the camera will notice

## Prop tracking

For every important prop, record: what it is, what it looks like, where it is at
the start of each scene, who holds it, and what state it is in (whole, broken,
open, lit, empty). A prop's state changes only through a story action:

- A letter is sealed, then opened, then read — each state is a storyboard fact.
- A cup is full, then drunk, then empty — never randomly full again.
- A vehicle is parked, then driven, then parked elsewhere — the new position is
  recorded in the continuity log.

## Rules

1. **Verbatim repetition** of the environment block in every clip set there.
2. **One location change = one storyboard beat.** Never change location
   mid-clip without a storyboard reason (a door opening onto a street is a
   transition, planned in advance).
3. **Background objects are not decoration.** If the storyboard lists a clock on
   the wall, the clock stays on the wall. Random background changes are a
   continuity defect.
4. **Lighting continuity.** Time of day and light direction persist across
   clips in the same scene. A morning scene does not become golden hour
   without a time jump the story declares.
5. **Check every clip.** Background continuity and prop state are QC items.
   A prop that teleports or changes shape is a failed clip within the retry
   budget.

## Honest limit

As with characters, each clip is a fresh render: backgrounds will vary in small
details no matter how precise the block. The skill minimises variation, checks
it, and reports significant breaks rather than pretending they do not exist.
